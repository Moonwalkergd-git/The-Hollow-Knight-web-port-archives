# The-Hollow-Knight-web-port-archives
An archive of many Hollow Knight Web Ports.



# General Information About Ports

808 mb hk by bog.html- The original Hollow Knight web port when it first came out ( Does not work )

Import saves hk by horiza.html- Dreamers fixed, and you can import saves. Use this one to mod off of.

Keystroke + FPS counter good ui fixed dreamers.html- Added keystrokes and fixed up importing save ui

Optimal hk modded.html - Use this one if you want to just play; includes speedrun timer and save imports.

Current patch.html - Current patch Hollow Knight port; however, it has many bugs. You may need to use the website instead of the HTML. Website:  https://glitches-hk-port.vercel.app/
